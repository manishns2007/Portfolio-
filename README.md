# 🌐 Personal Portfolio Website

A clean, modern **personal portfolio website** designed to showcase projects, skills, and professional experience in a visually engaging and user-friendly way.

This portfolio acts as a central hub for highlighting technical work, design sense, and overall profile — ideal for recruiters, collaborators, and peers.

---

## 🎯 Purpose of the Portfolio

The website is built to:

* Showcase featured projects with clear descriptions
* Highlight technical skills and tools
* Present professional background and achievements
* Provide easy ways to connect (GitHub, LinkedIn, Email)
* Create a strong first impression

---

## ✨ Key Features

* Minimal and modern UI
* Smooth layout and visual hierarchy
* Responsive design for all screen sizes
* Project-focused presentation
* Fast loading and optimized assets

## ▶️ Running Locally

You can run the portfolio locally using any static server.

Example using VS Code Live Server:

1. Open the project folder
2. Right-click `index.html`
3. Select **Open with Live Server**

Or using a simple server:

```bash
npx serve .
```
